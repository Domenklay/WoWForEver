# Донор Legion: подготовка Азсуны

Серверный источник — [AshamaneCore, ветка legion](https://github.com/AshamaneProject/AshamaneCore/tree/legion),
база [ADB_735.10](https://github.com/AshamaneProject/AshamaneCore/releases/tag/ADB_735.10).
Официальный архив скачан по HTTPS и прочитан библиотекой libarchive.
В нём world SQL (366 619 372 байта) и hotfix SQL (126 317 838 байт).
SHA-256 локального архива указан в provenance.json; опубликованный upstream digest
в списке release assets не предоставлен, поэтому сравнительная проверка с ним не заявляется.

В таблице creature обнаружено 27 568 строк спавнов на карте 1220.
Фильтр zoneId=7334 ничего не выбирает: 25 112 строк карты имеют zoneId=0.
Для одного участка Азсуны нужна выборка по координатам фактически выгруженного тайла.
В game_tele есть опорная точка Azsuna (-218.95, 5600.9, 61.1105), но безопасность
этой точки на Forever пока не проверена. Сейчас телепортировать туда персонажа нельзя.

Здесь только происхождение и результаты исследования. Исходные клиентские файлы
и большой архив БД в Git не добавляются. Рабочая БД пользователя не меняется.
Схемы Ashamane и Forever различаются; прямой импорт ADB в рабочую базу не предусмотрен.

Порядок получения и проверки ресурсов — [экспорт RAW](../../../docs/zones/LEGION-EXPORT.ru.md).
