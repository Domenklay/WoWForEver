# Цепочка Североземья из 3.3.5: пять заданий, три NPC

Отдельный набор поверх работающего Forever. Первый одиночный перенос
`northshire-335` можно оставить установленным: его ID и прогресс не меняются.
Этот набор проверяет цепочки, смену NPC при сдаче, выдачу документов и выбор оружия.
Он не добавляет новые карты или механики дополнений.

## Состав

Источник — официальная [TrinityCore TDB335.26091](https://github.com/TrinityCore/TrinityCore/releases/tag/TDB335.26091).
Архив `TDB_full_world_335.26091_2026_09_09.7z`, SHA-256:
`ed0c50177da912b50c9f386ba8a26254cecfb997ca7fd2e992c25b344e11274f`.
Исходные строки — `source.json`, лицензия GPL-2.0 (LICENSE / upstream COPYING).

| Порядок | Задание 3.3.5 | Новый ID | Проверка |
|---|---|---|---|
| 1 | A Threat Within (783) | 910783 | Взять у Виллема и сдать Макбрайду |
| 2 | Kobold Camp Cleanup (7) | 910007 | Убить 8 Kobold Vermin |
| 3 | Investigate Echo Ridge (15) | 910015 | Убить 8 Kobold Worker |
| 4 | Skirmish at Echo Ridge (21) | 910021 | Убить 8 Kobold Laborer; выбрать оружие |
| 5 | Report to Goldshire (54) | 910054 | Получить документы и доставить Дугхану в Златоземье |

Первые четыре задания возвращают игрока к тестовому Макбрайду.
Условия предыдущих заданий и ссылки на следующее перенаправлены на новые ID:
оригинальные задания не нужны для прохождения этой копии цепочки.
Квесты сохраняют исходные английские тексты и минимальный уровень 1;
уровни самих заданий — 1, 2, 3, 5, 5. Серверные rates влияют на выплаты.

Новые NPC имеют префикс **[335 chain]**:

- Deputy Willem — `910823`, рядом с оригинальным Виллемом у входа в аббатство.
- Marshal McBride — `910197`, рядом с оригинальным маршалом в аббатстве.
- Marshal Dughan — `910240`, рядом с оригинальным маршалом в Златоземье.

Их GUID спавнов — `910000001..910000003`. Позиции скопированы из Forever
со смещением (+3 по X, −1.5 по Y). На месте нужно проверить видимость и доступность:
SQL-проверка не доказывает, что NPC не оказался рядом со стеной.
Модели и боевые параметры наследуются из Forever; таблица NPC 3.3.5 напрямую не импортируется.

В цепочке три цели убийств и одна предметная цель: документ `745`, 1 шт.
За четвёртое задание предлагаются `2186`, `2691`, `11192` — один предмет на выбор.
Перед установкой проверяется, что оригинальные задания Forever уже используют
эти же предметы/документы. Это проверка ссылок; игровой тест выдачи всё равно нужен.
Существующие мобы используются как цели; их спавны и обычные квесты не изменяются.

## Установка

Выйдите из игры, оставьте Docker Desktop включённым. В Ubuntu:

```bash
cd ~/WoWForEver
git pull --ff-only
bash scripts/northshire-chain-port.sh apply
```

Команда сохранит четыре базы и настройки в `backups/`, остановит игровые службы
на время применения, затем снова запустит их. Бэкап содержит пароли и ключи:
не загружайте его в GitHub. Нужно свободное место под полный дамп.
Пересборка Docker, клиентский патч и новая сборка лаунчера не требуются для этого набора.

После установки:

```bash
bash scripts/northshire-chain-port.sh status
docker compose logs --since=3m --tail=60 worldserver
```

Дождитесь `ready` и начните у **[335 chain] Deputy Willem**. Не перепутайте с
`[335 test] Marshal McBride` от первого опыта или обычными NPC.

## Проверка в игре

1. У Виллема предлагается начальное задание, у Макбрайда ещё не открыты поздние этапы.
2. После сдачи начального задания открывается зачистка, далее следуют две стадии шахты.
3. Все три счётчика убийств требуют именно **8**, а не 10/12 из версии Forever.
4. После четвёртого задания можно выбрать и получить одно из трёх оружий.
5. При взятии Report to Goldshire в сумке появляется документ; сдать его нужно
   **тестовому Дугхану**, а не оригинальному NPC с тем же именем.
6. Проверьте изъятие документа при сдаче, деньги, опыт, репутацию и сохранение
   прогресса после выхода/повторного входа на любом промежуточном этапе.

Для чистого сравнения не берите одновременно обычный и тестовый варианты:
они намеренно используют тех же мобов и документ, поэтому возможен общий зачёт.
Человек Альянса уровня 1+ — рекомендуемый персонаж для теста. Новые ID независимы
от уже выполненных обычных заданий и первого тестового квеста.

## Откат

Сначала откажитесь от активных заданий с префиксом `[335 chain]` и выйдите из игры:

```bash
bash scripts/northshire-chain-port.sh rollback
```

Откат удалит только новые задания, связи и трёх NPC этого набора. Обычные
задания и первый одиночный порт остаются. Полученные предметы, деньги и история
выполнения на персонаже не откатываются. Документ может остаться, если квест
не был отменён штатно. Для повторного прохождения завершённой цепочки используйте
нового персонажа; полный возврат состояния требует восстановления бэкапа.

## Воспроизводимость и проверки

`python3 content/ports/northshire-chain-335/build.py` пересоздаёт SQL из снимка
источника без сети. Не редактируйте сгенерированные apply.sql/rollback.sql вручную.

Проверено в отдельной MySQL 8.0 на выбранных реальных таблицах официальной
базы Forever от 2026-10-14:

- 5 квестов, 3 NPC, все связи и предварительные условия, три цели убийств,
  предметная цель, выдача документа, ссылки на три награды;
- одновременная установка с одиночным портом, повторный запуск без дубликатов;
- откат, повторный откат, повторная установка, отказ при занятых ID;
- искусственная ошибка посередине установки: частичные изменения откатились;
- после очистки исходные данные таблиц совпали с состоянием до теста.

Общий shell-скрипт установки проверяется через `bash -n`. SQL-тест не заменяет
проверку клиента: новая цепочка в игре на 70532 пока не проверена.
