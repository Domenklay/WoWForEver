# Аддон ForeverEncyclopedia: UI-прототип
Скопируйте папку ForeverEncyclopedia в папку AddOns **фактической версии клиента** и включите в меню модификаций.
Команды /ency и /encyclopedia открывают окно. Это демонстрационный интерфейс, не рабочая серверная энциклопедия.
TOC Interface 110000 — временное значение; требуется определить Interface из действующего клиента 1.60.1.70532 и заменить. Включение «Устаревших модификаций» может потребоваться. API и шаблон BasicFrameTemplateWithInset пока не проверены на 70532.
Никаких сетевых сообщений или покупок UI не выполняет.
