# Каталог локаций: UX и индекс

## Игровое окно
Левая колонка: континент -> зона -> подзона/подземелье. Поиск по названию и фильтры «Все», «Не найдены», «Изучены», «Редкие», «Боссы».
Правая колонка: прогресс открытия зоны, вкладки «Существа», «Предметы», «Достижения», «Места».
Карточка существа: имя после открытия, иначе «???» и силуэт; категория, прогресс, статус «Встречен / Побеждён / Не найден», награда за первое убийство, найденная локация только при разрешённой политике подсказок.
Переключатель «Показывать неизвестных» и кнопка «Только доступные моему персонажу».
Если данных нет: «Для этой локации каталог ещё не сформирован», а не ложные 0/0.

## Индексация
Ключи: map_id, zone_id, area_id, creature_entry. Таблица индекса создаётся отдельным офлайн-проходом по creature spawns и area/zone mapping после проверки фактической схемы upstream forever.
У одного creature_entry может быть несколько зон. Ключ открытия всегда (account_id, creature, creature_entry), чтобы за одного моба не начислялись очки повторно в разных зонах.
Система считает процент как открытые доступные уникальные creature_entry / все доступные уникальные creature_entry в зоне; временные спавны, недоступные NPC, GM/test и скрытые записи фильтруются.
Победа над NPC в группе: награда только тем аккаунтам, которые удовлетворяют проверенному серверному правилу участия в убийстве. Не полагаться на клиентские события.
Предметы отображать по каталогу добычи зоны только при наличии проверенного серверного источника связи с зоной; не предполагать, что все item templates привязаны к локациям.

## Протокол
Аддон запрашивает страницу по zone/map/filter/page. Сервер возвращает только разрешённые записи, totals и version; аддон не является источником истины. Ограничение размера ответа и rate limit.
При первом убийстве сервер атомарно пишет discovery, начисляет очки и отправляет обновление счётчика.
Клиент 1.60.1.70532 требует отдельной проверки совместимости UI API и каналов передачи.

## Приёмка
Выбрать зону с 3 NPC, убить одного: прогресс 1/3; повторное убийство не меняет очки. Перейти другим персонажем того же аккаунта: 1/3. NPC в двух зонах не даёт двойной награды. В зоне без индекса интерфейс не показывает фиктивные 0%.
