# Forever Dungeon Finder 0.2 — подготовка для сервера 70658

Это экспериментальный клиентский аддон и C++ модуль, адаптированные под
действующий проект WoWForEver. **На рабочем сервере не установлены.**
Не использовать старый установщик из feature/forever-dungeon-finder:
он рассчитан на другой Docker Compose и может сломать готовый профиль.

## Интерфейс
- Штатное окно «Поиск группы» (если в клиенте открыт PVEFrame,
  LFGParentFrame или GroupFinderFrame): появляется кнопка-вкладка
  «Вход в подземелье». Внутри — список, поиск, описание, «Соло» и «Группой».
- При несовместимости фреймов остаются /fd или /dungeon:
  открывают самостоятельный список; при необходимости предусмотрена
  корректировка расположения вкладки после скриншота клиента.
- Не использует retail-пакеты очереди LFG и не подбирает случайных игроков.
  Требуется заранее сформированная группа, или можно войти одному.

## Серверная проверка
- Настройка FOREVER_DUNGEON_FINDER_ENABLED=0 по умолчанию.
- Код модуля компилируется в единый gameplay worldserver 70658 через
  scripts/inject-gameplay.py и scripts/inject-forever-dungeon-finder.py.
- Сообщения FDF SOLO:<mapId> (самому себе) и GROUP:<mapId> (PARTY)
  проверяются исключительно на сервере.
- Только 19 разрешённых Classic подземелий с реальной входной точкой
  на карте и типом IsNonRaidDungeon; произвольные карты не разрешены.
- Групповой вход запускает только лидер; рейды, офлайн-участники и
  группы более 5 человек запрещены. Все участники должны быть живыми,
  вне боя, не падать и не находиться на транспорте/в PvP инстансе.
- Телепорт происходит по штатной механике TrinityCore. Отдельные
  крылья подземелий с общим mapId пока ведут к стандартному входу.

## Известные ограничения
- Внутриигровое позиционирование вкладки требует проверки реальным
  клиентом 1.60.1.70658: пока использованы распространённые Frame-имена.
- Не реализованы автоматический подбор группы, подбор ролей, настройка
  наград и внутриигровой возврат через новую кнопку.
- Телепорт не гарантирует обхода ванильных требований к минимальному
  уровню или блокировок инстанса; их нужно проверить отдельно.
- Вход «Соло» из уже сформированной группы переносит только
  запрашивающего игрока, но может сохранить стандартную групповые
  привязки инстанса. Для полной изоляции нужны последующие тесты.
- Новый Scaling 0.4 для обычных подземелий и нейтралов — отдельный
  серверный эксперимент. На активном сервере по данным документации
  остаётся установлен Scaling 0.2.
