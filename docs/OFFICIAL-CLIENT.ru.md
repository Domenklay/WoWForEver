# Подключение официальной установки в Multi 1.3

Пользователь 6 ноября подтвердил загрузку ветки Forever 1.60 через Battle.net
и попросил подготовить наш лаунчер. Режим обслуживает подключение, а не
пересобирает клиент. Работающий clean-сервер сохраняется.

Проверка Windows читает FileVersion через version.dll, используя строковые
ресурсы EXE. Четырёх 16-битных полей VS_FIXEDFILEINFO недостаточно: сборка
70658 превышает 65535. `.build.info` используется как метаданные продукта и
языка, но не заменяет фактическую версию EXE. В интерфейсе обе версии видны
отдельно. Несовпадение сборки блокирует запуск до записи WTF и запуска EXE.

Профиль сервера по умолчанию содержит `clientBuild: 70658`; расширенное поле
должно соответствовать реальному серверу. Автоматической проверки этого
числа по удалённой базе и обновления сервера нет. Нельзя объявлять новую
сборку совместимой только изменением этого поля.

`protectClientFiles` по умолчанию true. IPC-команды client_work отклоняют
все действия, кроме verify; install_content и rollback_content также
отклоняются. Защита применяется до файловых транзакций и перед операциями
блокировки игрового состояния. Исторический false оставлен для изолированных
экспериментов и тестов; новый сценарий подключения принудительно сохраняет true.

Операция подключения читает каталог/EXE и сохраняет только настройки Multi.
При запуске разрешён отдельный WTF с адресом и языком и штатная подготовка
hosts/CA. Патчер проверяет полный массив известных ключей и меняет только
нужный публичный ключ в памяти выбранного по полному пути процесса. Ни
перепаковка CASC, ни перенос AddOns, ни восстановление индексов не входят
в этот сценарий. Сам игровой процесс может штатно изменять собственные
журналы, кеш и локальное состояние CASC.

Проверки: Windows API на настоящем системном файле; выбор совместимости по
версии EXE; блокировка разных веток и сборок; сохранение EXE, архивов,
индексов, shmem, .build.info и Config.wtf при подготовке сетевого профиля;
UI-проверки русского и ещё четырёх языков, несовместимой версии и отключения
файловых действий. Это не подтверждение полного входа в игру на ПК пользователя.
