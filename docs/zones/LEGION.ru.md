# Расколотые острова Legion: проверка перед переносом

Цель пользователя — отдельная локация Legion, а не ещё одна цепочка квестов
в существующем Североземье. Первый этап — карта Расколотых островов **1220**.
Наличие записей современных дополнений в ядре не доказывает наличие ресурсов
Legion в клиенте Forever 1.60.1.70532.

На компьютере, где уже работает Docker-сервер:

```bash
cd ~/WoWForEver
git pull --ff-only
bash scripts/legion-readiness.sh
```

Скрипт ничего не меняет: через существующий локальный SOAP запрашивает у ядра
`lookup map id 1220`, считает извлечённые terrain/vmap-файлы и показывает
расположение Map.db2. Пароли не выводятся. Сервер и сайт должны быть запущены.
Runtime lookup и подсчёт файлов на машине пользователя в разработке не выполнены:
отчёт нужно получить с его клиентских данных.

## Как интерпретировать отчёт

- Нет runtime-записи карты: сначала исследовать Map.db2 и соответствующие
  hotfix-записи; телепорт ещё не является корректной проверкой.
- Есть запись, но 0 terrain-файлов: ресурсы могли отсутствовать в клиенте,
  не загрузиться при потоковой установке или быть пропущены extractor.
  Нулевой счётчик сам по себе не доказывает отсутствие всей локации в CDN/клиенте.
- Есть terrain и vmaps: можно выбирать конкретный участок и проверять загрузку,
  рельеф, коллизии, воду и возврат персонажа. Это ещё не доказательство полноты зоны.
- mmaps не обязательны для текущего сервера с MMAP_PATHFINDING=0; для нормального
  поведения мобов позднее понадобятся навигация и игровые проверки.

## Следующий этап после отчёта

По реальным данным выбрать один участок Расколотых островов, а не переносить
весь Legion вслепую. До испытания сохранить позицию персонажа и бэкап.
Затем проверить доступные ресурсы участка, возможность входа и возвращения,
после этого добавлять спавны, предметы, задания и скрипты.

Клиентские карты, модели и текстуры сюда не коммитятся. Подмена MapID в SQL
не создаёт отсутствующую геометрию. wow.export/WoWDBDefs могут помочь исследованию,
но готовый проверенный конвейер переноса всех ресурсов Legion в 70532 не установлен.

Следующий этап: [выгрузка RAW-участка через wow.export](LEGION-EXPORT.ru.md).
