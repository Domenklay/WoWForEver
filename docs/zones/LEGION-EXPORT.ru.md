# Получение участка Даларана Legion без установленного Retail

Инструкция сверена с исходниками wow.export 0.2.19, коммит
`c2fd7bde36a712be78a5da896c995b84fbfa2545`. В другой версии расположение элементов
может отличаться. Пользователь уже передал манифест RAW-выгрузки пяти тайлов Даларана;
полнота зависимостей и совместимость с Forever ещё проверяются.

## 1. Источник ресурсов в Windows

Откройте [wow.export](https://www.kruithne.net/wow.export/), выберите
**Use Battle.net CDN**, регион **Europe**, затем обычный **World of Warcraft**.
На скриншоте пользователя доступна версия **12.1.5.70575**. Выбирайте её,
сохраните точный номер сборки. Не выбирайте Classic Beta 1.60.1.70532:
в его доступном Map.db2 нет записи карты 1220.

Дождитесь завершения загрузки индексов. В настройках **Export Directory**
создайте рабочие папки и укажите отдельный каталог экспорта:

```bash
mkdir -p /mnt/e/WoWForEver-work/exports/Legion-Dalaran-raw-v2
mkdir -p /mnt/e/WoWForEver-work/reports
```

В wow.export: `E:\WoWForEver-work\exports\Legion-Dalaran-raw-v2`.
Отчёты сохраняем в `E:\WoWForEver-work\reports`, не в корень диска. Папка нашего клиента
Forever и каталог его Data для экспорта не используются.

## 2. Первый небольшой экспорт

1. Откройте **Maps**. В фильтре найдите `Broken Isles`, `Расколотые острова`
   или ID **1220**. При необходимости отключите фильтр дополнений (Show All).
2. Для текущего опыта пользователь выбрал Даларан и соседние квадраты:
   `22_33`, `23_32`, `23_33`, `23_34`, `24_33` (индексы из имён файлов wow.export).
   Оставьте это выделение либо выберите его через **Shift + щелчок**.
   Азсуна была исходным предложением, но в текущем опыте используем Даларан.
3. Сначала на вкладке **Models** выберите в меню **Export Raw** (запускать
   отдельный экспорт модели не обязательно). Включите **M2 .skin Files**,
   **M2 .skel Files**, **M2 .bone Files**, **M2 .anim files**, **WMO Groups**.
   Это общие настройки, которые также читает экспорт карты.
   Вернитесь в **Maps**, включите **Export WMO**, **Export WMO Sets**, **Export M2**, **Textures**.
   Foliage можно включить; Export G-Objects для первого осмотра не обязателен.
4. В выпадающем меню экспорта выберите **Export Raw** и запустите экспорт.
   OBJ/PNG/Heightmaps не содержат нужного набора исходных игровых файлов.
5. Дождитесь результата. При ошибке сохраните текст/runtime.log; не считайте
   частичную выгрузку успешной. Некоторые файлы могут отсутствовать на CDN.

В исходниках RAW-экспорт сохраняет WDT, root ADT, tex0/obj0/obj1 и доступные
дополнительные файлы карты. Модели и текстуры зависят также от выбранных опций.
Это не доказательство замкнутости всех зависимостей.

## 3. Проверка выгрузки

Из Ubuntu:

```bash
cd ~/WoWForEver
git pull --ff-only
python3 scripts/audit-legion-export.py /mnt/e/WoWForEver-work/exports/Legion-Dalaran-raw-v2 \
  --build 12.1.5.70575 \
  --output /mnt/e/WoWForEver-work/reports/Legion-Dalaran-manifest.json
```

Новая папка отчётов при необходимости создаётся самим скриптом.
Укажите фактический путь и сборку, если они отличаются. Выходной JSON должен
лежать вне каталога экспорта. Пришлите **manifest.json и скриншот выбранного тайла**.
Сами большие игровые ресурсы пока никуда не загружайте.

Скрипт читает файлы, считает SHA-256, проверяет границы чанков WDT/ADT/WMO,
сигнатуры моделей/текстур/DB2 и наличие основных спутников root ADT.
Он также предупреждает, если при наличии M2 нет SKIN или у WMO есть GFID,
но в выгрузке нет групп MOGP. Ненулевые счётчики ещё не доказывают полноту каждой модели.
Он не меняет ресурсы, сервер, персонажей или клиент Forever.
MapID и номер сборки в отчёте — объявленные пользователем данные, не независимое
подтверждение происхождения. Код завершения 1 означает структурную ошибку либо
отсутствие WDT/root ADT; предупреждения тоже нужно просмотреть.

Даже чистый отчёт не доказывает совместимость с 70532 или полноту зависимостей.
После получения файлов исследуются форматы и ссылки FileDataID/DB2, доставка
ресурсов клиенту и повторное извлечение серверной геометрии. Готовый импортёр
Legion в Forever пока не реализован. Копировать RAW-папку в Data наугад нельзя.

## Состояние облачной проверки

GitHub доступен: исходники инструмента и серверная база получены.
HTTPS-запросы к eu.version.battle.net и www.kruithne.net из облачной среды
возвращают proxy 403. В черновике сетевой конфигурации сохранены добавления
`eu.version.battle.net`, `eu.cdn.blizzard.com`, `www.kruithne.net` с сохранением
существующих правил и presets. Сохранение черновика не применило доступ к
работающей машине. Может потребоваться разрешить дополнительные реальные
CDN-хосты после получения списка cdns; заранее неизвестные хосты не добавлялись.

## Разбор первого манифеста пользователя

Подтверждены 5 root ADT и их tex0/obj0/obj1/lod, основной WDT с MAIN/MPHD/MAID,
3 корневых WMO (включая dalaran2), 1972 M2 и 504 BLP. Общий размер учтённых
файлов — 181 170 407 байт. В отчёте нет SKIN и групп геометрии WMO (MOGP);
есть только корневые WMO с GFID. Исходный аудитор не выдавал предупреждений
об этих зависимостях, новая версия добавляет их.

Перед повторным экспортом используйте новую папку v2: в исходниках wow.export
есть условие пропуска блока объектов, если CSV размещения уже существует и
перезапись отключена. Поэтому смены флажков без новой папки/перезаписи недостаточно.
Старую выгрузку можно сохранить для сравнения. Файлы в Data клиента не копируются.

## Небольшой образец для анализа форматов

Второй манифест содержит 7269 файлов (554 871 512 байт), в том числе 2429 SKIN
и 336 групп WMO. Контрольные суммы всех 2509 файлов первого отчёта сохранились.
Появление зависимостей не доказывает их полную замкнутость или совместимость с 70532.

Чтобы не пересылать весь набор, соберите пакет одного тайла **23_33**:

```bash
cd ~/WoWForEver
git pull --ff-only
python3 scripts/package-legion-sample.py \
  /mnt/e/WoWForEver-work/exports/Legion-Dalaran-raw-v2 \
  --manifest /mnt/e/WoWForEver-work/reports/Legion-Dalaran-manifest.json \
  --tile 23_33 \
  --output /mnt/e/WoWForEver-work/samples/Legion-Dalaran-sample.zip
```

Каталог samples создаётся автоматически. Скрипт читает только выбранные файлы
из экспорта, проверяет размер и SHA-256 по отчёту и создаёт новый ZIP.
Существующий архив не перезаписывается. Изменённый после аудита ресурс приводит
к ошибке: в этом случае сначала пересоздайте манифест.

По текущему манифесту выбраны 18 исходных файлов, 4 626 615 байт до сжатия,
плюс до трёх небольших sidecar-файлов wow.export, если они существуют:
WDT, пять ADT выбранного тайла, корневой dalaran2.wmo и три его группы,
небольшая модель с SKIN и две текстуры. В sidecar-файлах могут быть полезные
ссылки FileDataID и таблица размещения объектов; их хеши отмечены как вычисленные
при упаковке, поскольку предыдущий аудитор не включал их в отчёт.

Это образец форматов, а не замкнутый набор зависимостей тайла: выбранные модели
и текстуры служат для исследования структуры. sample-index.json явно указывает
этот предел, происхождение отчёта и хеши всех вложений.

Пришлите ZIP из `E:\WoWForEver-work\samples`. Исходные ресурсы остаются на месте.
Клиент и сервер не изменяются. Сам ZIP с игровыми файлами в Git не добавляется.
