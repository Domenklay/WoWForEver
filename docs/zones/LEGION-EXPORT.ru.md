# Получение одного участка Азсуны без установленного Retail

Инструкция сверена с исходниками wow.export 0.2.19, коммит
`c2fd7bde36a712be78a5da896c995b84fbfa2545`. В другой версии расположение элементов
может отличаться. Онлайн-доступ и реальный экспорт ресурсов на стороне пользователя
ещё проверяются; наличие программы не означает готовность файлов для Forever.

## 1. Источник ресурсов в Windows

Откройте [wow.export](https://www.kruithne.net/wow.export/), выберите
**Use Battle.net CDN**, регион **Europe**, затем обычный **World of Warcraft**.
На скриншоте пользователя доступна версия **12.1.5.70575**. Выбирайте её,
сохраните точный номер сборки. Не выбирайте Classic Beta 1.60.1.70532:
в его доступном Map.db2 нет записи карты 1220.

Дождитесь завершения загрузки индексов. В настройках **Export Directory**
укажите отдельный каталог, например `E:\Legion-donor`. Папка нашего клиента
Forever и каталог его Data для экспорта не используются.

## 2. Первый небольшой экспорт

1. Откройте **Maps**. В фильтре найдите `Broken Isles`, `Расколотые острова`
   или ID **1220**. При необходимости отключите фильтр дополнений (Show All).
2. Откройте карту. Азсуна находится в юго-западной части Расколотых островов.
   Выберите **один квадрат суши** через **Shift + щелчок**. Сохраните скриншот
   выделенного квадрата/его индексов — он нужен для пространственной выборки NPC.
3. Включите **Export WMO**, **Export WMO Sets**, **Export M2**, **Textures**.
   Foliage можно включить; Export G-Objects для первого осмотра не обязателен.
4. В выпадающем меню экспорта выберите **Export Raw** и запустите экспорт.
   OBJ/PNG/Heightmaps не содержат нужного набора исходных игровых файлов.
5. Дождитесь результата. При ошибке сохраните текст/runtime.log; не считайте
   частичную выгрузку успешной. Некоторые файлы могут отсутствовать на CDN.

В исходниках RAW-экспорт сохраняет WDT, root ADT, tex0/obj0/obj1 и доступные
дополнительные файлы карты. Модели и текстуры зависят также от выбранных опций.
Это не доказательство замкнутости всех зависимостей.

## 3. Проверка выгрузки

Из Ubuntu:

```bash
cd ~/WoWForEver
git pull --ff-only
python3 scripts/audit-legion-export.py /mnt/e/Legion-donor \
  --build 12.1.5.70575 --output /mnt/e/Legion-donor-manifest.json
```

Укажите фактический путь и сборку, если они отличаются. Выходной JSON должен
лежать вне каталога экспорта. Пришлите **manifest.json и скриншот выбранного тайла**.
Сами большие игровые ресурсы пока никуда не загружайте.

Скрипт читает файлы, считает SHA-256, проверяет границы чанков WDT/ADT/WMO,
сигнатуры моделей/текстур/DB2 и наличие основных спутников root ADT.
Он не меняет ресурсы, сервер, персонажей или клиент Forever.
MapID и номер сборки в отчёте — объявленные пользователем данные, не независимое
подтверждение происхождения. Код завершения 1 означает структурную ошибку либо
отсутствие WDT/root ADT; предупреждения тоже нужно просмотреть.

Даже чистый отчёт не доказывает совместимость с 70532 или полноту зависимостей.
После получения файлов исследуются форматы и ссылки FileDataID/DB2, доставка
ресурсов клиенту и повторное извлечение серверной геометрии. Готовый импортёр
Legion в Forever пока не реализован. Копировать RAW-папку в Data наугад нельзя.

## Состояние облачной проверки

GitHub доступен: исходники инструмента и серверная база получены.
HTTPS-запросы к eu.version.battle.net и www.kruithne.net из облачной среды
возвращают proxy 403. В черновике сетевой конфигурации сохранены добавления
`eu.version.battle.net`, `eu.cdn.blizzard.com`, `www.kruithne.net` с сохранением
существующих правил и presets. Сохранение черновика не применило доступ к
работающей машине. Может потребоваться разрешить дополнительные реальные
CDN-хосты после получения списка cdns; заранее неизвестные хосты не добавлялись.
