# Аддоны обычного клиента в тестовой копии Даларана

Для совместной проверки используем **установленные файлы обычного клиента**,
а не версии из main: разработка Freepick продолжается в другой ветке.

Закройте обе копии игры и программы обновления аддонов. В WSL обновите только
скрипт, сохранив ветку и Dockerfile:

```bash
cd ~/WoWForEver
git fetch origin main
git restore --source=FETCH_HEAD --worktree -- scripts/copy-client-addons.py
python3 scripts/copy-client-addons.py \
  --source /mnt/e/_classic_beta_ \
  --target /mnt/e/WoWForEver-work/experiments/Forever-Legion-client-v1/_classic_beta_ \
  --backup "/mnt/e/WoWForEver-work/backups/addons-test-$(date +%Y%m%d-%H%M%S)"
```

Скрипт копирует всю установленную папку `Interface/AddOns`: получается такой
же набор кода, включая библиотеки и зависимости. Старый набор тестовой копии
сохраняется в `before` резервной папки; аддоны, которые были только в тестовой
копии, также останутся в этой резервной копии. Затем заменяется тестовая папка
AddOns. Файлы действительно копируются, общих ссылок и hardlink не создаётся.
SHA-256 проверяются до переключения и после него; при ошибке переключения
возвращается прежняя папка. Источник не переписывается.

`WTF`, SavedVariables, макросы аккаунта, исполняемые файлы, CASC и сервер не
копируются и не меняются. Настройки аддонов в тестовой копии поэтому могут
отличаться. Обе копии по-прежнему подключаются к одному серверу: персонажи,
изученные способности и серверный прогресс общие. Копирование аддонов не создаёт
отдельную игровую базу или отдельный сервер.

Запускайте тестовую папку через лаунчер, проверьте вход в обычный мир и интерфейс
Freepick (`/fsub`), затем сравнение текстур. Перед телепортом нужно отдельно
подтвердить чтение нового ресурса движком. Успешное копирование не доказывает
совместимость всех аддонов: её проверяем в игре.

Откат файлов аддонов (игра закрыта), с точным путём из строки `Backup:`:

```bash
python3 scripts/copy-client-addons.py \
  --restore /mnt/e/WoWForEver-work/backups/addons-test-ДАТА-ВРЕМЯ
```

Перед откатом текущие тестовые аддоны также сохраняются в
`after-before-restore` резервной папки.
