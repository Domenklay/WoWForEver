# Новый контроль: изменить существующий ID текстуры

Новые приватные ID пока остаются зелёными. Перестановка TVFS и добавление
ROOT-варианта не помогли; ETL не дал пригодного результата. Вместо ещё одной
проверки процессов проводим эксперимент без регистрации нового FileDataID:
штатный `123086` временно получает содержимое другой штатной BLP-текстуры.

Это новый эксперимент, а не подтверждённое исправление. Если изображение
изменится, это подтвердит применение нашей правки существующего ID клиентом.
Зелёный квадрат или прежнее изображение сами по себе не установят причину:
останутся формат/маршрут метаданных, выбор хранилища, варианты и кэш клиента.

Работаем в прежней независимой копии. Полный сброс не требуется: предыдущие
слои сохраняются, новый контроль откатывается отдельной командой. Новые игровые
данные и ID не добавляются, исходный клиент и сервер не меняются. Поскольку
ID существующий, его изображение временно изменится и в других местах копии,
где он используется. Проверку выполняем в обычном мире без телепортации.

## 1. Проверка без установки

Закройте игру и лаунчер. Команды выполняются в **WSL Ubuntu**, не PowerShell.
Для использования кода из репозитория:

```bash
cd ~/WoWForEver
python3 scripts/repair-legion-tvfs-entry.py native-control-check \
  /mnt/e/WoWForEver-work/experiments/Forever-Legion-client-v1
```

Используйте версию скриптов, содержащую команды `native-control-*`. Если код
передан ZIP-архивом, инструкции по запуску находятся в `START.ru.md` архива;
обновление Git для такого запуска не требуется.

Скрипт проверит прежние установленные ресурсы через CascLib, найдёт среди
следующих 128 штатных ID локально читаемую BLP с точно такими же locale/type/
variant-профилями, проверит маршруты TVFS и чтение выбранных двух ID. Конфигурация
клиента не изменится. Если подходящей пары нет, операция остановится, не
устанавливая контроль; автоматической подстановки несовместимых профилей нет.

В `E:\WoWForEver-work\reports` появится `Dalaran-native-control-*.json`.
Терминал напечатает `Target ID`, `Donor ID` и строку `/run WFCdonor=ЧИСЛО`.
При необходимости конкретный донор задаётся `--donor-id ЧИСЛО`; все проверки
совместимости остаются обязательными.

## 2. Сначала увидеть обе исходные текстуры

### Если проверка пары остановилась на чтении штатного ID

В первом запуске пользователя все 8655 установленных ресурсов прошли проверку,
и для `123086` найден совместимый донор `123087`. Затем проверка самого
`123086` остановилась. Первоначальное сообщение скрывало строку результата
CascLib, поэтому причина — ошибка открытия/чтения или несовпадение CKey — пока
не установлена. Контроль не установлен, откат не требуется.

Для такого случая добавлена отдельная команда без повторного сканирования
всего пакета. С закрытыми игрой и лаунчером:

```bash
python3 scripts/repair-legion-tvfs-entry.py native-control-probe \
  /mnt/e/WoWForEver-work/experiments/Forever-Legion-client-v1 --donor-id 123087
```

Она читает только два ID через CascLib, выводит исходные ROOT-профили, результаты
чтения их содержимого независимым Python-аудитором и фактические строки CascLib,
включая неуспешные. Вывод также сохраняется в `Dalaran-native-control-*.json`
каталога отчётов. Клиент не меняется. Ошибка одного reader не доказывает, что
игровой движок читает ресурс так же. До разбора результата установку не запускаем.

### Если проверка пары завершилась успешно

Запустите прежнюю тестовую копию и войдите в обычный мир. Выполните напечатанную
скриптом строку `/run WFCdonor=ЧИСЛО`, затем две строки:

```lua
/run if WFC then WFC:Hide() end;WFC=CreateFrame("Frame",nil,UIParent);WFC:SetSize(660,240);WFC:SetPoint("CENTER")
/run for i,id in ipairs({123086,WFCdonor,15728640}) do local t=WFC:CreateTexture();t:SetSize(200,200);t:SetPoint("LEFT",(i-1)*220,0);t:SetTexture(id) end
```

Слева исходный ID `123086`, в центре выбранный донор, справа прежний приватный
ID. **Первые две картинки должны отображаться и различаться.** Сделайте
скриншот «до». Если слева/в центре зелёный квадрат или изображения одинаковы,
не устанавливайте контроль: передайте скриншот и JSON плана для выбора пары.
Затем полностью закройте игру и лаунчер.

## 3. Установка и сравнение

Подставьте фактический `Donor ID` вместо `ЧИСЛО`:

```bash
python3 scripts/repair-legion-tvfs-entry.py native-control-apply \
  /mnt/e/WoWForEver-work/experiments/Forever-Legion-client-v1 \
  --donor-id ЧИСЛО
```

Проверяется та же пара. Все ROOT-профили ID `123086` сохраняют ID, локаль, флаги,
хеши имён и положение; меняются только их CKey на CKey соответствующих профилей
донора. В штатных дочерних TVFS добавляются пути существующего целевого ID к
тем же VFS-строкам, что использует донор. Старые пути и непрозрачные CFT-записи
сохраняются. ROOT/TVFS/ENCODING/build config устанавливаются согласованным слоем.
Тела игровых ресурсов не копируются и не переписываются.

До записи создаётся резервная копия метаданных. После установки обязательное
чтение CascLib должно вернуть по целевому ID хеш донора и сохранить все остальные
контрольные ресурсы. Сбой проверки вызывает откат нового слоя. Нужна строка
`NATIVE TEXTURE CONTROL INSTALLED`; ошибка не означает успешную установку.

После успеха запустите ту же копию заново и повторите три Lua-строки с тем же
донором. Сделайте скриншот «после», закройте игру и лаунчер.

- Слева теперь изображение донора: клиент применил перенаправление существующего
  ID. Это положительный контроль правки метаданных; регистрацию нового ID и
  загрузку карты он ещё не доказывает.
- Слева прежняя картинка: клиент не применил ожидаемое перенаправление. Это не
  доказательство запуска другого EXE; пока нельзя отличить выбор маршрута,
  формата, источника данных и кэша.
- Слева зелёный квадрат/ошибка загрузки: маршрут изменён или отвергнут; успешное
  чтение CascLib не гарантирует поддержку этого маршрута игровым движком.

## 4. Откат только этого контроля

С закрытыми игрой и лаунчером:

```bash
python3 scripts/repair-legion-tvfs-entry.py native-control-rollback \
  /mnt/e/WoWForEver-work/experiments/Forever-Legion-client-v1
```

Предыдущий эксперимент с приватной текстурой сохраняется. Повторная команда
остановится, если активен уже не этот контроль; прежние слои не снимаются.
При установке автоматически собирается ZIP отчёта, но его логи предшествуют
новому игровому тесту. Для дальнейшего разбора нужны план JSON, скриншоты
«до»/«после» и, при необходимости, свежий `collect-legion-report.py`.

Проверки разработки: синтетические ROOT с несколькими вариантами и именованными
группами; сохранение непрозрачных CFT и старых TVFS-путей; несовместимые профили;
запрет повторной установки; проверка без записи; установка, принудительный отказ
чтения и точный откат на собственном хранилище. В тесте транзакции чтение выполняет
Python-аудитор. Это не проверка настоящего клиента или native CascLib; при
установке на ПК пользователя чтение настоящим CascLib обязательно.
