# Пакетная установка ресурсов Даларана в тестовую копию

Этот шаг действительно записывает подготовленные приватные ресурсы в CASC.
Результат — проверенный на чтение пакет в копии клиента. Запись Map 1220 ещё
не подключается: запуск локации, серверная геометрия, население и квесты остаются
отдельными задачами. Успешный импорт ресурсов не означает готовность карты.

## Установка

Полностью закройте игру и лаунчер. Сохраните пакет v2 и исходный клиент.
Используется уже созданная независимая копия, в которой работал canary.
Установщику понадобится дополнительное место для нового сегмента (несколько
сотен MiB), резервных копий метаданных и ещё 256 MiB запаса. Временная обработка
больших манифестов также требует свободной оперативной памяти.

В WSL:

```bash
cd ~/WoWForEver
git pull --ff-only
python3 scripts/install-legion-resources.py apply \
  /mnt/e/WoWForEver-work/experiments/Forever-Legion-client-v1 \
  --resource-report /mnt/e/WoWForEver-work/packages/Legion-Dalaran-private-v2/report.json
```

Ожидаются 2912 новых приватных ID и 4192 общих ресурса. Скрипт:

1. Проверяет ZIP, внутренний индекс, хеши приватных файлов и привязки ID.
2. Читает исходные ID через CascLib с локалью ruRU, проверяет каждый общий
   ресурс и контрольные файлы. Учитывает все локали ROOT при проверке коллизий.
3. Создаёт резервную копию `.build.info`, всех IDX, shmem и прочих метаданных.
4. Добавляет отдельный нативный сегмент и новые поколения всех 16 IDX;
   старые архивы `data.NNN` остаются нетронутыми. Обновляет ROOT, ENCODING,
   DOWNLOAD и TVFS, затем переключает `.build.info` только в тестовой копии.
5. Повторно читает каждый новый ID и все ранее успешно прочитанные исходные
   ID, сравнивает размеры, SHA-256 и CKey. Для старых ресурсов проверяет также
   неизменность масок DOWNLOAD. При ошибке после начала записи запускает откат.

Один сегмент ограничен 1 GiB, номера сегментов — 255. Инструмент откажется
от записи, если не хватает места в нативных IDX или сегменте. Поддержка текущего
пакета не означает возможность сразу импортировать произвольные 4 GiB ресурсов.

Существующий CKey может иметь другое кодирование. Для такого случая добавляется
проверенный N-вариант с сохранением всех прежних вариантов и ESpec. Для уже
читаемых CKey сохраняется членство DOWNLOAD; для новых используется маска
проверенных контрольных ресурсов. Старые записи DOWNLOAD не переписываются.

## Что прислать и проверить в игре

После строки `PRIVATE RESOURCES INSTALLED AND READ VERIFIED` скрипт напечатает
путь к `result.json`. Пришлите этот небольшой файл; `operation.json` и игровые
архивы пересылать не нужно.

В лаунчере выберите игровую папку именно тестовой копии:

```text
E:\WoWForEver-work\experiments\Forever-Legion-client-v1\_classic_beta_
```

Запустите игру и войдите существующим персонажем в привычную локацию. Сообщите,
успешно ли вошли в мир. Даларан на этом этапе ещё не активирован, команды
телепортации на Map 1220 пока не используем. Реальный запуск WowB.exe нельзя
подтвердить облачными тестами или успешным чтением через CascLib.

ROOT новых ресурсов использует **экспериментальную общую группу без хешей имён**,
как в ранее проверенном canary. Это проверка пакетной записи и доступности ID;
политика типов terrain/WDT и загрузка карты игрой пока не подтверждены.
Все ограничения разбора зависимостей сохраняют силу. Защищённый Map.db2 этим
шагом не заменяется, серверные файлы и настройки не меняются.

## Откат

Если игра сообщает о повреждении установки, закройте игру и лаунчер. В WSL:

```bash
cd ~/WoWForEver
python3 scripts/install-legion-resources.py rollback \
  /mnt/e/WoWForEver-work/experiments/Forever-Legion-client-v1
```

Восстанавливаются метаданные и `.build.info` перед пакетной установкой. Новый
сегмент и изменённые клиентом метаданные сохраняются в карантине внутри папки
операции. Восстанавливаются и старые IDX, которые клиент мог удалить при ошибке.
Используйте откат этого установщика, а не команды старого canary: это разные
операции. После отката предыдущий canary остаётся на месте.

Для повторной проверки установленного пакета при закрытой игре:

```bash
python3 scripts/install-legion-resources.py verify \
  /mnt/e/WoWForEver-work/experiments/Forever-Legion-client-v1
```

Если клиент изменил новые архивы или поколения IDX, проверка остановится.
Не исправляйте это удалением файлов вручную; журнал и резервные копии нужны
для отката.
