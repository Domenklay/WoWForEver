# Геометрия одного тайла Даларана

Пользователь подтвердил вход в существующий мир из тестовой копии после установки
2912 приватных ресурсов. Теперь извлекаем рельеф и столкновения размещённых моделей
для одного тайла. Карта 1220 пока не включена для персонажей.

Закройте игру и лаунчер. В WSL выполните:

```bash
cd ~/WoWForEver
git pull --ff-only

python3 scripts/extract-legion-geometry.py \
  /mnt/e/WoWForEver-work/experiments/Forever-Legion-client-v1 \
  --resource-report /mnt/e/WoWForEver-work/packages/Legion-Dalaran-private-v2/report.json \
  --map-report /mnt/e/WoWForEver-work/packages/Legion-Dalaran-map-v1/report.json \
  --output /mnt/e/WoWForEver-work/geometry/Legion-Dalaran-tile-v1
```

Нужно минимум 2 ГиБ свободного места и уже созданный локальный Docker-образ
`forever-legion-casc-probe:local`, который использовался для проверок CASC.
Повторная сборка сервера не требуется. Инструменты пересобирают только две точки
входа экстракторов и небольшую программу проверки высоты, используя готовые
объекты сборки закреплённой ревизии TrinityCore.

Сначала проверяются все 8655 ресурсов установленного слоя. Затем контейнер читает
клиент через том только для чтения, без сети. Результат записывается исключительно
в новую папку `geometry/Legion-Dalaran-tile-v1`. Если папка уже существует,
выберите новое имя, например `Legion-Dalaran-tile-v2`.

Отправьте файл:

```text
E:\WoWForEver-work\geometry\Legion-Dalaran-tile-v1\report.json
```

При ошибке отчёт и журналы в подпапке `logs` сохраняются. Если команда остановилась
до создания отчёта, пришлите текст ошибки. Не копируйте полученные файлы в данные
работающего сервера самостоятельно.

## Что проверяет эксперимент

Экстракторам явно передаются карта 1220 и приватный WDT 15730590. Это обходит
недоступные зашифрованные секции Map.db2 только внутри инструментов; сама таблица
клиента не заменяется. Проверяются ревизия ядра, исходники экстракторов и привязка
отчётов к уже установленному пакету.

У экспортированного тайла `23_33` координаты сетки сервера — X=33, Y=23.
Ожидаемый файл рельефа: `maps/1220_33_23.map`; столкновения:
`vmaps/1220/1220.vmtree` и `vmaps/1220/1220_33_23.vmtile`, плюс модели `.vmo`.
Общий каталог моделей игровых объектов не извлекается и не заменяется.

После сборки VMAP программа на основе серверного VMapManager проверяет высоту
поверхности в 121 точке тайла. Отдельно учитываются попадания на высоте города
500–1500, чтобы не принять нижележащий рельеф за пол Даларана. Успех этой выборки
ещё не доказывает наличие всех столкновений или безопасную точку появления.

Компиляция инструментов и проверка высот испытаны в облаке на собственной
геометрии из двух треугольников: 110 попаданий на ожидаемую высоту 735; отсутствующий
тайл отклонён. Игровые ресурсы в этой проверке не использовались. Извлечение
настоящего Даларана требует запуска приведённой команды на компьютере пользователя.

После разбора отчёта следующий этап — отдельно подготовить включение карты
на клиенте и сервере с откатом, затем проверить прибытие персонажа. НПС и монстры
добавляются после проверки поверхности.
