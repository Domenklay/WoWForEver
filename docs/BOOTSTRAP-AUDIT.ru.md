# Проверка служебных манифестов после полной загрузки

Crash 70658 от 6 ноября 2026 показал 64 streaming-ошибки: таймауты и 404
при чтении patch/*.index, а также Invalid CDN Index file size. Клиент уже
побывал в мире около пяти секунд; аддоны не были загружены. Это подтверждённые
ошибки стриминга, но текстовый стек без символов не доказывает единственную
причину ACCESS_VIOLATION.

Пользовательская полная проверка новой папки clients/70658 сообщила complete=true,
checked=1125135, missing=0, unverifiable=0. Эта проверка сравнивает выбранные
DOWNLOAD-объекты, распакованные INSTALL-файлы и целостность индексированных
BLTE. Она не доказывает наличие всех отдельных служебных манифестов.
INSTALL и DOWNLOAD установщик получает для разбора, но старый worker не сохраняет
их BLTE-копии явно в CASC. Их реальное отсутствие требует отдельной проверки;
нельзя объявлять это доказанной причиной падения без результата локального аудита.

Закройте игру и выполняйте из текущего checkout в WSL:

```bash
python3 scripts/audit-managed-bootstrap.py --client /mnt/e/WoWForEver-work/clients/70658
```

Проверка не делает сетевых запросов, не изменяет клиент, не включает ремонт и
не читает базы/сессии лаунчера. Читает активный BuildConfig, ENCODING, отдельные
INSTALL/DOWNLOAD/SIZE/ROOT и VFS через действующие локальные IDX-поколения.
Каждый найденный объект декодируется с проверкой CKey. Отсутствующие записи
показываются отдельно; большой список ограничен 32 строками с полным счётчиком.
Если файлы хранилища меняются во время проверки, результат отвергается.

bootstrap_complete — только проверка перечисленных метаданных, а не всех
ресурсов или успешной игры. Не удаляйте Data, .idx, конфиги и старые установки
по одному сравнению файлов. Исправление должно сохранить уже скачанное
содержимое; произвольная подмена CDNConfig, размеров или отключение проверок
хешей не является восстановлением.
