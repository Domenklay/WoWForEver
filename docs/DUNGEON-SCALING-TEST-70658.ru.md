# Проверка Scaling 0.4 и Forever Dungeon Finder 0.2 (70658)

Это план для тестовой установки на отдельно собранном worldserver и
изолированной копии баз. Рабочий forever-clean по документации остаётся на
Scaling 0.2.0. Не выполнять reset/install-dev/down -v и не откатывать
готовый сервер ради смены версии.

## Автолевелинг и опыт

1. Персонаж уровня 20, красный NPC исходно уровня 10:
   отображаемый уровень NPC должен быть 17; опыт за убийство не должен
   быть серым (если этот NPC штатно даёт опыт).
2. Персонаж уровня 60, красный NPC исходно уровня 20:
   отображение 57, опыт согласно штатной формуле.
3. Нейтральный жёлтый боевой NPC исходно уровня 10+: он масштабируется
   по тем же правилам при атакуемости по правилам ядра.
4. Нейтральный NPC исходного уровня 5 и мирный торговец/квестодатель:
   уровень не изменяется.
5. NPC исходно выше игрока никогда не снижается.
6. Два игрока разных уровней одновременно видят одного противника на
   соответствующих персональных уровнях; здоровье/бой общие.
7. Без изменений: союзные NPC, PvP, питомцы игроков.

## Подземелье и прямой вход

1. Подключить новый клиентский тестовый ForeverDungeonFinder через
   общий testing/addons-70658. Открыть стандартное «Поиск группы»,
   проверить вкладку «Вход в подземелье»; запасной вызов /fd.
2. Выбрать «Мёртвые копи», нажать «Соло». Убедиться, что перенесён
   один персонаж и сервер вернул подтверждение/обычную ошибку, а не
   запустил очередь LFG. Повторить с персонажем в обычной группе:
   соло не должно перемещать других участников.
3. Сформировать обычную группу 2–5 игроков: только лидер может нажать
   «Группой»; все онлайн и вне боя. Все попадают в один экземпляр.
4. Не должны проходить: участник офлайн, бой, смерть, падение,
   транспорт/vehicle, PvP, рейд, чужой mapId через FDF.
5. Групповой тест 1/2/3/4/5: фиксация состава на начале боя, проверка
   относительного HP и исходящего урона обычных NPC, элиты и босса.
6. Во время боя новый игрок входит в подземелье: коэффициент уже
   начатого боя не должен изменяться.
7. Wipe/evade/respawn: HP и максимальное HP восстанавливаются без
   удвоения/залипания коэффициентов, награды и лут не дублируются.
8. Убедиться, что старые крылья с общим mapId (Алый монастырь,
   Мародон, Забытый город) пока приводят к стандартной точке входа.
9. Проверить, что привычный поиск группы и все другие аддоны работают.

## Управление и границы

Серверные флаги новой тестовой версии (по умолчанию выключены):
- FOREVER_SCALING_ENABLED=1;
- FOREVER_SCALING_MIN_OFFSET=-3;
- FOREVER_DUNGEON_SCALING_ENABLED=0 (ставить 1 только в изолированном тесте);
- FOREVER_DUNGEON_FINDER_ENABLED=0 (ставить 1 только в изолированном тесте).

Скопировать Lua-файлы на клиент можно через тестовый канал Multi,
если установлен соответствующий Multi; серверная часть не
устанавливается этим каналом. Без нового server image кнопка портала
не телепортирует. Нужны отдельно сборка pinned core, бэкап четырёх БД,
изолированная копия, готовый откат на прежний Docker image и
игровая приёмка. Текущий READY-профиль не переключался.

Проверки исходников: GitHub PR #3 и gameplay-70658 CI.
