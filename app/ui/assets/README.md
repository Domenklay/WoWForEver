# Astral Workshop art

Original assets generated for Forever Multi 1.2 on 2026-11-05; no Blizzard art,
logos, characters or game resources were used. The theme is an astral
cartographer's workshop: ink, sea glass and aged copper.

- `astral-workshop.webp`: 1536 × 1024 hero illustration, generated as an original
  scene and encoded as WebP for packaging.
- `workshop-sprites.webp`: 1536 × 1024 RGBA atlas, 3 columns × 2 rows. CSS uses the
  six cells directly, without individual image files. Top: compass, download,
  verification shield. Bottom: repair tool, atlas, settings cog. Hover/focus/
  disabled/busy states use CSS; reduced-motion preferences are respected.

Original full-size PNGs remain in the generation workspace. Preview screenshots
in docs/screenshots use mocked server responses and a synthetic account;
they do not demonstrate live world entry.
